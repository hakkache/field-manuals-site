Structured Streaming · State · failure 05 of 16

State grows until the query dies.

Failure family · State Structured Streaming · part 06 · failure 05 of 16
Symptom
A stateful query runs fine for weeks, then slows steadily and eventually fails with memory errors. Restarting helps briefly.
Cause
No watermark. Without one, state for every key is retained indefinitely — the engine has no basis for deciding a key is finished. This is the most common stateful streaming outage there is.
Fix
Add a watermark with withWatermark("event_time", "10 minutes") before the stateful operation. Caveat: adding a watermark to an existing query changes the stateful operation, which the checkpoint locks — so in practice this means a new checkpoint. Note that complete output mode never drops state, so on complete mode with a growing key space the mode itself is the problem.

Check first — Alert on state size per operator, not just on throughput. A stateful operator with no watermark grows without bound for weeks before it dies, and state size is where it shows up first — long before the memory error.
