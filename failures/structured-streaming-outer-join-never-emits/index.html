Structured Streaming · Semantics · failure 10 of 16

The outer join never emits anything.

Failure family · Semantics Structured Streaming · part 06 · failure 10 of 16
Symptom
A stream-stream left outer join produces matched rows but never the expected null-padded unmatched ones — or produces nothing at all.
Cause
Watermarking is mandatory for outer joins. It is what tells the engine when an unmatched key must finally be written with a null. Without it — or without an appropriate range condition — the engine can never decide a row has waited long enough.
Fix
Set a watermark on both sides and add a time-range condition to the join so 'final' is well defined. Expect the delay: because joins only append, unmatched data is not recorded until after the lateness threshold has passed. Remember that stream-stream joins support append mode only.

Check first — An outer join is inherently later than the matched path — that is by design, not a bug. If unmatched rows are missing entirely, check that both sides carry a watermark and that the join has a time-range condition; without both, the engine never emits the null-padded side.
